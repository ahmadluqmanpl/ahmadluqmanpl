## 🚀 Featured Projects

### 🎓 UTeM GPA/CGPA Calculator

<a href="https://github.com/ahmadluqmanpl/UTeM-GPA-CGPA-Calculator">
<img src="https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github" alt="GitHub Repository" />
</a>

An unofficial GPA and CGPA calculator created to make academic calculations and consultation preparation easier for UTeM students.

```txt
Platforms  : Windows (.exe), Android (.apk), Web
Built with : JavaScript, HTML/CSS, Electron, Capacitor, Cloudflare Workers
Privacy    : Local profile storage & session-only web data
```

**Main Features**

```txt
• Credit-weighted GPA and CGPA calculation
• Windows, Android and Web support
• Offline multi-profile storage with auto-save
• Searchable bundled UTeM programme catalogue
• Academic consultation report preview
• A4 PDF export
• Input validation & structured data handling
```
