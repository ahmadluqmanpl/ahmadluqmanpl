## 🧩 Featured Project

</div>

### 🎓 UTeM GPA CGPA Calculator

An unofficial GPA and CGPA calculator built to help UTeM students calculate, track, and prepare academic reports more easily.

```txt
Status       : Active
Type         : Web app and Windows desktop app
Built with   : JavaScript, Electron, HTML, CSS
Purpose      : Student academic planning
```

#### Features

- GPA and CGPA calculation
- Programme selection
- Online session-only report details
- Offline Windows app with local profile support
- PDF report preview and print/save support
- Clean interface for student use

#### Disclaimer

This project is unofficial and is not affiliated with Universiti Teknikal Malaysia Melaka.  
Results should always be verified with official academic records.
